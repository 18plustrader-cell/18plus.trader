Setup — 5 minutes

Get it running

1

Get the two apps

You need TradingView Desktop (the app, not the website — set your default exchange to NSE) and Claude Code (free with any Claude plan). Node.js 18+ if you don't have it.

→ tradingview.com/desktop · claude.com/code · nodejs.org

2

Install the bridge

Clone the open-source MCP server and install its dependencies.

git clone https://github.com/tradesdontlie/tradingview-mcp.git ~/tradingview-mcp
cd ~/tradingview-mcp && npm install
3

Launch TradingView in debug mode

The bridge talks to the app through Chrome DevTools Protocol, so TradingView must start with a debug flag. Quit TradingView first, then run:

open -a TradingView --args --remote-debugging-port=9222

Windows: run scripts\launch_tv_debug.bat from the repo instead. Every restart of TradingView needs this flag — if you open it normally later, the connection drops until you relaunch this way.

curl http://127.0.0.1:9222/json/version

That should print JSON. Use 127.0.0.1, not localhost — localhost can resolve to IPv6 and fail.

4

Connect it to Claude Code

claude mcp add --scope user tradingview -- node ~/tradingview-mcp/src/server.js

User scope = available in every project. Verify with claude mcp list — you want tradingview ✔ Connected.

5

Test it

Open a new Claude Code session and ask:

Use tv_health_check to verify TradingView is connected.

What it can actually do

Prompt it. Watch the chart move.

🔍 "Go through my watchlist and give me the best NSE chart to trade"

Claude flipped the chart through every symbol on the watchlist, pulled weekly candles and RSI for each, computed trend/momentum/volatility across the board — and surfaced Aurobindo Pharma as the strongest setup, with reasoning.

🌊 "Map the Elliott Wave count and draw the trade plan with Pine Script"

Claude read the weekly structure on Dixon Technologies, labelled a full five-wave impulse and an A-B-C corrective sequence, then wrote the levels — invalidation, target, and the resistance-turned-support zone — as a Pine v6 script, compiled it, and applied it to the chart. Every level is an editable input.

Map the Elliott Wave count on the DIXON weekly chart, mark waves (1) through (5) and the A-B-C correction, and draw the target zone using Pine Script.

🧪 "Turn it into a strategy and backtest it"

An indicator draws levels; a strategy can be tested. Ask Claude to convert the plan into a Pine strategy() — entries, exits, stop and target as real orders — then open the Strategy Tester. It reads the results back: net profit, win rate, profit factor, max drawdown and the trade list, on NSE data.

Convert this trade plan into a Pine v6 strategy with entry, stop and target orders. Compile it, open the Strategy Tester, and tell me the net profit, win rate, profit factor, max drawdown and number of trades.
Why it matters: most AI chart posts stop at a pretty picture. A backtest is the difference between a setup that looks good and one that survived history. Fewer than ~30 trades or a suspiciously perfect equity curve is a red flag, not a green light.

🛡️ "Audit the strategy — is it real or overfit?"

Now make Claude interrogate its own work. It reviews the strategy code and the backtest stats for the ways strategies lie: curve-fit parameters, too few trades, look-ahead bias, no out-of-sample check, and rules that only worked in one regime — like a single bull leg on the Nifty.

Audit this strategy for overfitting and bias. Check: how many inputs were tuned, whether any rule uses future data, trade count and sample size, performance in different market conditions (bull, bear, range-bound Nifty), and what would break it. Be skeptical — argue the bear case against your own strategy.
This is the whole edge. An AI that only ever agrees with itself is dangerous. Forcing it to attack its own idea is how you avoid trading a hope with extra math. The final call — and every real order — stays with you.

! Good to know

Before you prompt

It's your account, your limits.On the free/Basic TradingView plan you get 2 indicators per chart — Claude works within that (it swaps indicators in and out). Paid plans remove the friction.
All local.The bridge connects to the app on your machine only — no TradingView API, no broker credentials, no data sent anywhere.
NSE/BSE data quirks.Delivery-only and circuit-filter stocks can gap through levels; treat Pine backtests on illiquid small-caps with extra scepticism.
AI can be wrong.Treat every setup, wave count, and backtest as a starting point, not a signal. Sizing and risk are on you.
